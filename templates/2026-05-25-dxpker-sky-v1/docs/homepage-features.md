# Homepage Features

## 視覺結構

- 淺藍漸層背景（`#B4D0EF` → `#E3EBF6`），上深下淡
- 白色 / 半透明白卡片浮在背景上
- 主按鈕用 `linear-gradient(180deg, #4FB2FF, #2F8DE0)` 立體感

## 功能區

| Section | 用途 |
|---------|------|
| App 下載 bar | 引導使用者下載 App |
| Hero banner | 主視覺 + 合作俱樂部（含 placeholder）|
| 公告 Marquee | 跑馬燈訊息 + 公告列表入口 |
| 登入卡 | 未登入提示 + CTA |
| 加值服務專員 | 客戶服務浮按鈕（左下） |
| 主功能 Grid | 3 個主功能入口（棋牌 / 真人 / 體育）|
| 其他玩法 | 8 個次要分類 icon |
| Tab Bar | 4 個主導航（首頁/活動/客服/我的）|

## Placeholder 模式（IP 區隔）

本版型 6 個 placeholder 區為刻意設計，業務端塞自有素材後即為完整品牌頁。詳見 `README.md` 表格。
